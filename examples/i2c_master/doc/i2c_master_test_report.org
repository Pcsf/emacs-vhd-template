* Anomalies
:PROPERTIES:
:CUSTOM_ID: anomalies
:END:

No test failed.  These are behaviours the tests brought out that a user
of the block would not expect.  AN-06 was fixed in the design: START hold,
repeated START setup, STOP setup and the bus free time are now two quarter
periods, and four monitors and five mutants guard them.  For the others
the VHDL was not changed; each is written
into the [[file:i2c_master_icd.org::#limitations][limitations of the ICD]] and is an [[file:i2c_master_srs.org::#open-points][open point]] where a
decision is needed.  Severity is the tester's proposal.
