* Clocks and resets
:PROPERTIES:
:CUSTOM_ID: clocks
:END:

| Clock | Frequency | Source    | Used by         | Constraint                |
|-------+-----------+-----------+-----------------+---------------------------|
| clk   | 100 MHz   | top level | the whole block | ~create_clock~ at the top |

- Reset is synchronous and active high, applied in ~regs~ with ~REG_RESET~
  as both the reset and the initial value, so simulation and the
  bitstream start in the same state.
- Nothing is reset asynchronously.  An external button goes through
  ~reset_sync~ at the top level.
- ~SOFT_RST~ ([[file:demo_icd.org::#reg-control][ICD, CONTROL]]) is a second source of the same reset term in ~comb~:
  ~v := REG_RESET~ when it is set.

* Block design
:PROPERTIES:
:CUSTOM_ID: design
:END:

** Structure
:PROPERTIES:
:CUSTOM_ID: structure
:END:

Two-process style (~two_process~ template): ~comb~ computes the next state
~v~ from ~r~ and the inputs, ~regs~ clocks ~rin~ into ~r~.  Outputs are
driven from register fields, never from ~comb~ directly, so every output is
glitch-free and timing starts at a flop.

| ~reg_type~ field | Width |  Reset | Purpose                             |
|------------------+-------+--------+-------------------------------------|
| ~state~          |  enum | ~IDLE~ | State of the [[#fsm][control FSM]]            |
| ~busy~           |     1 |      0 | ICD STATUS.BUSY                     |
| ~done~           |     1 |      0 | ICD STATUS.DONE, cleared by W1C     |
| ~err~            |     1 |      0 | ICD STATUS.ERR                      |
| ~count~          |     8 |      0 | Operation timer, bounds the latency |

** Control FSM
:PROPERTIES:
:CUSTOM_ID: fsm
:END:

| State    | Meaning               | Leaves on                 | To       | Outputs        |
|----------+-----------------------+---------------------------+----------+----------------|
| ~IDLE~   | Waiting for start     | ~start~ rising, ~err~ = 0 | ~RUN~    | busy=0         |
| ~RUN~    | Operation in progress | datapath finished         | ~FINISH~ | busy=1         |
|          |                       | ~count~ = max             | ~FAULT~  |                |
| ~FINISH~ | One clock             | always                    | ~IDLE~   | done=1, busy=0 |
| ~FAULT~  | Error latched         | ~SOFT_RST~                | ~IDLE~   | err=1          |

- The state is an enumeration; the ~others~ branch returns to ~FAULT~ with
  ~err~ set, so an illegal encoding is reported, not silently recovered.
- ~start~ is a level: the rising edge is detected on a registered copy, so
  holding it high starts exactly one operation ([[file:demo_srs.org::#REQ-001][REQ-001]]).

** Register interface
:PROPERTIES:
:CUSTOM_ID: register-interface
:END:

~axi_lite_regs~ holds CONTROL and SCRATCH and returns STATUS and VERSION.
CONTROL bits are levels into ~comb~; STATUS is assembled from ~r~ fields.
DONE is write-1-to-clear: the clear is a one-clock term in ~comb~, so a
clear and a new completion in the same clock keep the completion.
