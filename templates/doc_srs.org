# reused once published; gaps are fine, renumbering is not.  Add the next

# which is generated from them, so nothing is typed twice:
#   METHOD   T test, A analysis, I inspection, D demonstration
#   TEST     the test case or the report that verifies it
#   DESIGN   the part of the design description that implements it (a link)
#   ICD      the ICD clause that exposes it (a link)
#   MONITOR  the testbench monitor that enforces it, if there is one
#   RESULT   PASS, FAIL, OPEN (not yet run), or N/A with a reason
#   STATUS   proposed, approved, verified, deleted
#
# One "shall" per requirement: "and" usually means two.  No rationale, no
# requirement: the question to answer is whether the application needs it.
