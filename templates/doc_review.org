| Item                                                            | OK/NOK/NA | Note |

** Clock domain crossings

| Item                                                            | OK/NOK/NA | Note |
|-----------------------------------------------------------------+-----------+------|
| Every crossing is in the design description                     |           |      |
| Single bits: synchronizer fed by a register, attribute set      |           |      |
| Words: handshake or asynchronous FIFO, never per-bit            |           |      |
| Each crossing has its timing constraint                         |           |      |
| The CDC report shows no unconstrained crossing                  |           |      |

** Code

| Item                                                            | OK/NOK/NA | Note |
|-----------------------------------------------------------------+-----------+------|
| Outputs are driven from registers                               |           |      |
| Every combinational variable has a default before it is used    |           |      |
| The FSM ~case~ has an ~others~ that recovers                    |           |      |
| No latches, no combinational loops (synthesis log)              |           |      |
| Counters and comparisons sized; no off-by-one at the wrap       |           |      |
| Memories are their own entity and infer as intended             |           |      |
| Debug marks and debug code removed, or documented as kept       |           |      |
