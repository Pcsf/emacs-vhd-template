* Checklist

** Requirements and interface

| Item                                                              | OK/NOK/NA | Note |
|-------------------------------------------------------------------+-----------+------|

| VERSION value equals the ICD version                               |           |      |

** Reset and clocks

| Item                                                              | OK/NOK/NA | Note |
|-------------------------------------------------------------------+-----------+------|
| One reset strategy: synchronous, active high, ~REG_RESET~          |           |      |
| Reset and initial values are the same constant                    |           |      |
| No asynchronous reset on fabric registers                         |           |      |
| External reset goes through ~reset_sync~                          |           |      |
| Every clock has a ~create_clock~                                   |           |      |

** Clock domain crossings

| Item                                                              | OK/NOK/NA | Note |
|-------------------------------------------------------------------+-----------+------|
| Every crossing is in the HDD table                                 |           |      |
| Single bits: ~sync_2ff~, source is a register, ~ASYNC_REG~ set     |           |      |
| Words: ~bus_sync_handshake~ or ~fifo_async~, never per-bit sync     |           |      |
| Each crossing has its ~set_max_delay~ / ~set_false_path~           |           |      |
| ~report_cdc~ shows no unconstrained crossing                       |           |      |

** Code

| Item                                                              | OK/NOK/NA | Note |
|-------------------------------------------------------------------+-----------+------|
| Two-process style, outputs driven from ~r~ fields                 |           |      |
| Every ~comb~ variable has a default before it is used             |           |      |
| ~case~ on the FSM state has an ~others~ that recovers              |           |      |
| No latches, no combinational loops (synthesis log)                |           |      |
| Counters and comparisons sized; no off-by-one at the wrap         |           |      |
| Memories are their own entity and infer as intended               |           |      |
| ~mark_debug~ and debug code removed, or documented as kept         |           |      |
